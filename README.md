# wzx-xle/scoop-bucket

wzx-xle 个人 [Scoop](https://scoop.sh) bucket。

## 安装

```powershell
scoop bucket add wzx-xle https://github.com/wzx-xle/scoop-bucket
scoop install <app>
```

## 包含应用

- [cc-launcher](https://github.com/wzx-xle/cc-launcher) — Terminal launcher for Claude Code with provider switching and permission mode selection
